---
name: blog-thumbnail
description: Make a local thumbnail for a blog post.
---

1. Read the title, author, category and date from the
   supplied post. Ask if a value is missing.
2. Copy template.html from this skill folder into a fresh
   output folder as thumbnail.html. Replace the four
   marked text values with the post details as plain text.
3. In a browser, open the copy at 1200 × 630 CSS pixels.
   Keep the full title. If it touches the footer, reduce
   the heading size in the copy until both fit.
4. At 1× scale, capture the card as thumbnail.png.
   Return the HTML and PNG. Leave the post unchanged.
