# Nick Dimitratos’ agent skills

I’m [Nick Dimitratos](https://ndimitratos.com/about), a full-stack engineer. I keep the skills I share in my articles here so you can read the instructions, inspect the files and try the examples in your own projects.

| Skill | What it makes | Walkthrough |
| --- | --- | --- |
| [Blog thumbnail](skills/blog-thumbnail/) | A 1200 × 630 cover image and editable HTML from a post’s title, author, category and date. | [Why I Made an AI Skill for My Blog Thumbnails](https://ndimitratos.com/articles/why-i-made-an-ai-skill-for-my-blog-thumbnails/) |
| [Agent visitor audit](skills/agent-visitor-audit/) | A read-only report on a specific visitor task and the evidence an agent can find. | [Your next website visitor might be an AI agent](https://ndimitratos.com/articles/your-next-website-visitor-might-be-an-ai-agent/) |

Each skill lives in its own folder under `skills/`. Start with the folder’s README for an example prompt and expected output, or open its `SKILL.md` to read the instructions your agent will follow.
